# auraZigbee

Smart clock with **Zigbee®**

## Features
 - 32x8 LED matrix display
 - Time synchronization over Zigbee
 - Temperature and humidity measurement
 - Light level measurement
 - Automatic display brightness control
 - Multiple clock styles

## Hardware
 - Arduino Nano Matter
 - Arduino Nano Connector Carrier
 - Arduino Modulino Thermo
 - Arduino Modulino Light
 - MAX7219 32x8 LED Matrix Display
